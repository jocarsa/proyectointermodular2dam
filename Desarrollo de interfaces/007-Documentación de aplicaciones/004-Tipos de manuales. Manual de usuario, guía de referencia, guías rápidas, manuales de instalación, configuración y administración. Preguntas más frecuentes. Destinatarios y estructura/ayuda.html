Descripción de la aplicación

La calculadora de precios permite obtener el precio final de una compra a partir de cuatro datos:

  • precio unitario del producto;
  • cantidad de unidades compradas;
  • porcentaje de IVA;
  • porcentaje de descuento.

La aplicación calcula automáticamente el subtotal, el descuento aplicado, el IVA y el total final.

Cómo usar la calculadora

  1. Introduce el precio unitario del producto.
  2. Introduce la cantidad de unidades.
  3. Introduce el porcentaje de IVA.
  4. Introduce el porcentaje de descuento.
  5. Pulsa el botón Calcular.
  6. Consulta los resultados que aparecen debajo del formulario.

Si algún dato no es válido, la aplicación mostrará un mensaje de error y no realizará el cálculo.

Datos que debe introducir el usuario

Precio unitario

Es el precio de una sola unidad del producto. Debe ser un número mayor o igual que cero.

Cantidad

Es el número de unidades compradas. Debe ser un número mayor que cero.

IVA

Es el porcentaje de impuesto que se aplica sobre la base con descuento. Por ejemplo, un IVA del 21% debe introducirse como 21.

Descuento

Es el porcentaje que se descuenta sobre el subtotal. Por ejemplo, un descuento del 10% debe introducirse como 10.

Resultados que muestra la aplicación

Después de pulsar el botón Calcular, la aplicación muestra varios resultados.

  • Subtotal: precio unitario multiplicado por la cantidad.
  • Descuento: importe que se resta al subtotal.
  • IVA: impuesto calculado sobre la base con descuento.
  • Total final: cantidad definitiva que debe pagar el usuario.

Ejemplo de cálculo

Si el precio unitario es 100 €, la cantidad es 2, el IVA es 21% y el descuento es 10%, el cálculo sería:

  • Subtotal: 100 × 2 = 200 €
  • Descuento: 10% de 200 = 20 €
  • Base con descuento: 200 - 20 = 180 €
  • IVA: 21% de 180 = 37,80 €
  • Total final: 180 + 37,80 = 217,80 €

Errores frecuentes

La aplicación muestra un mensaje de error

Esto ocurre cuando alguno de los datos introducidos no es válido.

Algunos casos que producen error son:

  • dejar un campo vacío;
  • introducir una cantidad igual a cero;
  • introducir valores negativos;
  • introducir datos que no sean numéricos.

La cantidad no puede ser cero

La cantidad representa el número de unidades compradas. Por eso debe ser mayor que cero. No tendría sentido calcular una compra de cero productos.

El IVA se calcula después del descuento

En esta aplicación primero se aplica el descuento y después se calcula el IVA sobre la base resultante.
