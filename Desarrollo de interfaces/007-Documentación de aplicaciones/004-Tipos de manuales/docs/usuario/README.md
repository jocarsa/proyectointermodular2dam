# Manual de usuario

Bienvenido a la documentación de usuario de la calculadora de precios.

Esta documentación explica cómo utilizar la aplicación desde el punto de vista del usuario final.

---

## ¿Para qué sirve la aplicación?

La calculadora permite obtener el precio final de una compra aplicando:

- precio unitario;
- cantidad;
- IVA;
- descuento.

La aplicación calcula automáticamente:

- subtotal;
- descuento aplicado;
- IVA;
- total final.

---

## Cómo usar la calculadora

1. Abre el archivo `calculadoraPrecios.html`.
2. Introduce el precio unitario del producto.
3. Introduce la cantidad de unidades.
4. Introduce el porcentaje de IVA.
5. Introduce el porcentaje de descuento.
6. Pulsa el botón `Calcular`.
7. Consulta los resultados mostrados en pantalla.

---

## Ejemplo de uso

Datos introducidos:

```txt
Precio unitario: 100
Cantidad: 2
IVA: 21
Descuento: 10
```

Resultado esperado:

```txt
Subtotal: 200 €
Descuento: 20 €
IVA: 37,80 €
Total final: 217,80 €
```

---

## Errores habituales

La aplicación mostrará un mensaje de error cuando alguno de los datos introducidos no sea válido.

Por ejemplo:

- si un campo está vacío;
- si la cantidad es cero;
- si algún valor es negativo;
- si se introduce un valor no numérico.
